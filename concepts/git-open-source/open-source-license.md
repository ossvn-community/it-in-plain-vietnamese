# Open-source License là gì?

Open-source License - giấy phép mã nguồn mở - là văn bản quy định người khác được phép sử dụng, sửa đổi và phân phối source code theo những điều kiện nào.

Đưa code lên GitHub ở chế độ public không tự động có nghĩa là người khác được quyền sử dụng nó theo cách họ muốn.

## Ví dụ

Một project có thể chọn MIT License để cho phép sử dụng và phân phối rộng rãi với điều kiện giữ thông báo bản quyền và giấy phép. Các license khác có thể đặt thêm yêu cầu khác.

## Dễ nhầm với gì?

License là vấn đề pháp lý. Khi chọn license cho project thực tế, nên đọc điều khoản của license và hướng dẫn chính thức thay vì chỉ dựa vào mô tả ngắn.
