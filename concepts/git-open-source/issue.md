# Issue là gì?

Issue là một mục dùng để theo dõi một vấn đề hoặc công việc trong quá trình phát triển project.

Issue có thể ghi bug, feature request, câu hỏi, task hoặc một chủ đề cần thảo luận.

## Ví dụ

Một bug có thể được tạo thành issue với:
- hiện tượng;
- cách tái hiện;
- kết quả mong đợi;
- thông tin môi trường.

Sau đó commit hoặc Pull Request sửa bug có thể liên kết lại với issue đó.

## Dễ nhầm với gì?

Issue không phải Pull Request. Issue mô tả hoặc theo dõi công việc; Pull Request đề xuất một tập thay đổi code để review và merge.
