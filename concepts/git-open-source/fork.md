# Fork là gì?

Fork là một repository được tạo từ một repository khác để bạn có không gian riêng phát triển thay đổi mà không sửa trực tiếp repository gốc.

Trên GitHub, fork vẫn giữ mối liên hệ với repository gốc, thường gọi là upstream.

## Ví dụ

Bạn muốn sửa một dự án open source nhưng không có quyền push. Bạn có thể:
1. Fork repository về tài khoản của mình.
2. Tạo branch và commit thay đổi trong fork.
3. Mở Pull Request về repository gốc.

## Dễ nhầm với gì?

Fork khác branch. Branch là một nhánh bên trong cùng repository; fork là một repository riêng.
