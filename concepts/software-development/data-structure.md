# Data Structure là gì?

Data Structure - cấu trúc dữ liệu - là cách tổ chức dữ liệu để chương trình có thể lưu, tìm, thêm, xóa hoặc xử lý dữ liệu thuận tiện hơn.

Các data structure khác nhau phù hợp với các kiểu công việc khác nhau.

## Ví dụ

Một danh sách việc cần làm có thể được lưu dưới dạng list. Một bảng tra cứu `username -> profile` phù hợp hơn với cấu trúc key-value như dictionary hoặc map.

## Dễ nhầm với gì?

Data Structure không đồng nghĩa với database. Data structure thường nói về cách dữ liệu được tổ chức trong chương trình; database là hệ thống dùng để lưu và quản lý dữ liệu lâu dài.
