# Algorithm là gì?

Algorithm - thuật toán - là một chuỗi bước rõ ràng để giải một bài toán hoặc hoàn thành một công việc.

Khi lập trình, algorithm mô tả **cách xử lý**. Code là cách bạn biểu diễn algorithm đó bằng một ngôn ngữ lập trình cụ thể.

## Ví dụ

Muốn tìm số lớn nhất trong một danh sách, một cách đơn giản là:
1. Giữ lại số lớn nhất đã thấy.
2. Đi lần lượt qua các số còn lại.
3. Nếu gặp số lớn hơn, cập nhật kết quả.

Đó là một algorithm. Bạn có thể viết nó bằng Python, JavaScript, C++ hoặc ngôn ngữ khác.

## Dễ nhầm với gì?

Không phải algorithm nào cũng cần phức tạp hoặc dùng toán cao cấp. Với người mới, điều quan trọng là nhìn một bài toán thành các bước có thứ tự và điều kiện rõ ràng.
