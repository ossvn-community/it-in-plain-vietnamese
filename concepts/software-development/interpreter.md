# Interpreter là gì?

Interpreter - trình thông dịch - là chương trình đọc và thực thi code thông qua môi trường chạy của ngôn ngữ.

Với người dùng, trải nghiệm thường là có thể chạy code trực tiếp mà không cần tự tạo một file thực thi riêng trước.

## Ví dụ

Khi mở Python interpreter và nhập `print("Hello")`, Python đọc câu lệnh và thực thi nó ngay trong phiên làm việc đó.

## Dễ nhầm với gì?

Ranh giới compiler và interpreter không phải lúc nào cũng tuyệt đối. Một runtime có thể vừa biên dịch một phần code vừa thực thi qua interpreter hoặc virtual machine.
