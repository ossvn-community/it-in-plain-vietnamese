# Package là gì?

Package là một đơn vị đóng gói code và metadata để có thể phân phối, cài đặt hoặc tổ chức lại dễ hơn.

Cách một package được định nghĩa cụ thể phụ thuộc vào hệ sinh thái ngôn ngữ.

## Ví dụ

Trong Python, một project có thể được đóng gói và phát hành để người khác cài bằng công cụ như `pip`. Trong JavaScript, package thường được phân phối qua registry như npm.

## Dễ nhầm với gì?

Package và library thường liên quan nhưng không đồng nghĩa. Một package là đơn vị đóng gói/phân phối; bên trong nó có thể cung cấp một library, command-line tool hoặc loại phần mềm khác.
