# Programming Language là gì?

Programming Language - ngôn ngữ lập trình - là cách con người viết các chỉ dẫn để máy tính thực hiện hoặc xử lý một công việc.

Mỗi ngôn ngữ lập trình có các quy tắc riêng về cách viết và ý nghĩa của chương trình.

## Ứng dụng phổ biến

Ngôn ngữ lập trình được dùng để tạo nhiều loại phần mềm khác nhau, ví dụ:

- Python thường được dùng cho automation, xử lý dữ liệu và AI.
- JavaScript thường được dùng để tạo phần tương tác của website.
- Swift và Kotlin thường được dùng để phát triển ứng dụng trên iOS và Android.

Một ngôn ngữ có thể được dùng cho nhiều mục đích khác nhau, không chỉ những ví dụ trên.

## Ví dụ

Python:

```python
name = "Nam"
print(name)
```

JavaScript:

```javascript
const name = "Nam";
console.log(name);
```

Hai đoạn code được viết khác nhau nhưng đều lưu một giá trị rồi hiển thị nó.

Trong tài liệu kỹ thuật, cách viết của ngôn ngữ thường được gọi là **syntax - cú pháp**, còn ý nghĩa của các cấu trúc được gọi là **semantics - ngữ nghĩa**.

## Dễ nhầm với gì?

**Programming language không phải compiler hay interpreter.** Ngôn ngữ lập trình định nghĩa cách viết và ý nghĩa của chương trình; compiler hoặc interpreter là phần mềm xử lý code viết bằng ngôn ngữ đó.
