# Framework là gì?

Framework là một bộ cấu trúc, quy ước và công cụ giúp bạn xây một loại ứng dụng theo cách đã được định hướng sẵn.

Thay vì chỉ gọi một vài function như khi dùng library, framework thường quyết định một phần cách project được tổ chức và cách code của bạn được framework gọi.

## Ví dụ

Django định hướng cách một web application Python tổ chức URL, view, model và nhiều thành phần khác. React, Vue hoặc Angular định hướng cách xây giao diện web theo những mô hình riêng.

## Dễ nhầm với gì?

Library thường là thứ code của bạn gọi. Với framework, framework thường kiểm soát flow chính và gọi code bạn viết tại những điểm được quy định. Đây là cách phân biệt thực dụng, không phải ranh giới tuyệt đối.
