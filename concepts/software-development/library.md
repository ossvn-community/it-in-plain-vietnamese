# Library là gì?

Library - thư viện - là code đã được đóng gói để chương trình khác có thể tái sử dụng.

Thay vì tự viết lại mọi thứ từ đầu, bạn có thể gọi các function, class hoặc API mà library cung cấp.

## Ví dụ

Python có standard library với các module như `json`, `datetime` và `pathlib`. Chương trình có thể dùng chúng để xử lý JSON, ngày giờ hoặc đường dẫn file mà không cần tự xây lại các chức năng cơ bản.

## Dễ nhầm với gì?

Library thường cung cấp các khối chức năng để code của bạn gọi. Framework thường đi xa hơn và định hình cách cả ứng dụng được tổ chức.
