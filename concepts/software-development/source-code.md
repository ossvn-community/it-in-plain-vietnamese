# Source Code là gì?

Source Code - mã nguồn - là phần code mà developer viết bằng ngôn ngữ lập trình để mô tả chương trình.

Source code có thể được compiler, interpreter hoặc các công cụ khác xử lý trước hoặc trong lúc chương trình chạy.

## Nó được dùng thế nào?

Tùy language và toolchain, source code có thể được:

- compiler dịch sang dạng khác trước khi chạy;
- interpreter đọc và thực thi;
- hoặc trải qua nhiều bước build khác.

Vì vậy, **source code không đồng nghĩa với executable file**.

## Ví dụ

File Python:

```python
# hello.py
print("Hello")
```

`hello.py` là source code của chương trình ví dụ này.
