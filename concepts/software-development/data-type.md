# Data Type là gì?

Data Type - kiểu dữ liệu - cho biết một giá trị thuộc loại nào và chương trình có thể thực hiện những thao tác nào với giá trị đó.

Số, chuỗi ký tự, boolean và list là những ví dụ quen thuộc về data type.

## Ví dụ

Trong Python:

```python
age = 20
name = "Nam"
```

`20` là một integer, còn `"Nam"` là một string.

Các type khác nhau hỗ trợ operation khác nhau. Ví dụ, cộng hai integer và nối hai string là hai hành vi khác nhau dù đều có thể dùng toán tử `+` trong Python.

## Thử ngay

```python
print(type(20))
print(type("Nam"))
```
