# Control Flow là gì?

Control Flow - luồng điều khiển - là thứ tự chương trình chọn và thực thi các câu lệnh.

Các cấu trúc như `if`, loop và function call giúp chương trình quyết định đoạn code nào chạy tiếp theo.

## Ví dụ

```python
age = 20

if age >= 18:
    print("adult")
else:
    print("minor")
```

Điều kiện quyết định một trong hai nhánh được chạy.

Loop cho phép lặp lại một phần chương trình:

```python
for i in range(3):
    print(i)
```
