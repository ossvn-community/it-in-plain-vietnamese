# Compiler là gì?

Compiler - trình biên dịch - là chương trình chuyển source code từ một dạng ngôn ngữ sang một dạng khác để máy tính hoặc công cụ tiếp theo có thể xử lý.

Trong nhiều ngôn ngữ, compiler tạo ra machine code hoặc một dạng mã trung gian trước khi chương trình chạy.

## Ví dụ

Với C, bạn có thể dùng GCC để biên dịch file `main.c` thành chương trình thực thi. Source code con người đọc được sẽ được compiler phân tích và chuyển thành output phù hợp với nền tảng đích.

## Dễ nhầm với gì?

Compiler không phải programming language. C là một ngôn ngữ; GCC là một bộ compiler có thể xử lý code C và một số ngôn ngữ khác.
