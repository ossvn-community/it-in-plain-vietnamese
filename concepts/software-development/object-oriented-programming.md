# Object-Oriented Programming là gì?

Object-Oriented Programming - lập trình hướng đối tượng, thường viết tắt là **OOP** - là cách tổ chức chương trình quanh các object có dữ liệu và hành vi liên quan.

OOP là một cách thiết kế code, không phải yêu cầu bắt buộc để viết mọi chương trình.

## Ví dụ

Một object `BankAccount` có thể giữ số dư và cung cấp các thao tác như `deposit()` hoặc `withdraw()`. Code liên quan tới tài khoản được nhóm vào cùng một abstraction thay vì rải rác ở nhiều nơi.

## Dễ nhầm với gì?

OOP không đồng nghĩa với việc phải dùng inheritance ở mọi nơi. Class, object, encapsulation, inheritance và polymorphism là các khái niệm thường gặp, nhưng cách áp dụng phụ thuộc ngôn ngữ và thiết kế.
