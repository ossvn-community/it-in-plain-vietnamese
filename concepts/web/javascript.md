# JavaScript là gì?

JavaScript là ngôn ngữ lập trình được dùng rộng rãi trên Web để thêm logic và tương tác cho trang.

Trình duyệt có thể chạy JavaScript để phản hồi thao tác của người dùng, thay đổi nội dung trang, gọi API hoặc xử lý dữ liệu.

## Ví dụ

Khi người dùng bấm nút “Hiện thêm”, JavaScript có thể bắt sự kiện click rồi thêm nội dung mới vào trang mà không cần tải lại toàn bộ.

## Dễ nhầm với gì?

JavaScript không phải Java. Đây là hai ngôn ngữ khác nhau dù tên giống nhau.
