# CDN là gì?

CDN - Content Delivery Network - là mạng các server phân tán ở nhiều vị trí để đưa nội dung tới người dùng từ điểm phù hợp hơn.

CDN thường giúp giảm độ trễ và giảm tải cho server gốc khi phân phối file tĩnh, video hoặc nội dung có thể cache.

## Ví dụ

Một website đặt ảnh ở server gốc tại châu Á nhưng dùng CDN có điểm hiện diện ở nhiều khu vực. Người dùng ở châu Âu có thể nhận bản cache từ một điểm gần hơn thay vì mọi request đều quay về server gốc.

## Dễ nhầm với gì?

CDN không thay thế hoàn toàn hosting hoặc server gốc. Nó thường đứng giữa người dùng và origin để phân phối hoặc cache nội dung.
