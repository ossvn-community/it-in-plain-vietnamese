# Browser là gì?

Browser - trình duyệt - là application dùng để truy cập và hiển thị nội dung trên Web.

Browser nhận tài nguyên như HTML, CSS và JavaScript, xử lý chúng rồi tạo giao diện mà người dùng nhìn và tương tác.

## Nó làm gì khi mở một trang?

Ở mức đơn giản, browser:

1. Nhận [URL](url.md) người dùng muốn mở.
2. Dùng [DNS](dns.md) khi cần để tìm địa chỉ server.
3. Gửi [HTTP](http.md) request tới server.
4. Nhận các tài nguyên như [HTML](html.md), CSS, JavaScript, ảnh.
5. Xử lý và render chúng thành giao diện người dùng nhìn thấy.

## Tại sao cần nó?

Browser không chỉ hiển thị text. Nó là môi trường chạy phần lớn code phía client và triển khai nhiều Web standards.

## Thử ngay

Mở Developer Tools của browser, chọn tab `Network`, reload trang và xem các HTTP request được tạo khi trang tải.

## Dễ nhầm với gì?

**Browser không phải search engine.** Browser là ứng dụng truy cập Web; search engine là một dịch vụ Web giúp tìm nội dung.
