# CSS là gì?

CSS - Cascading Style Sheets - là ngôn ngữ dùng để mô tả cách nội dung HTML được trình bày trên màn hình hoặc các thiết bị khác.

Nếu HTML nói một trang có tiêu đề, đoạn văn và nút bấm, CSS quyết định chúng trông như thế nào: kích thước, khoảng cách, màu sắc, bố cục và khả năng thích ứng với màn hình.

## Ví dụ

```css
button {
  font-size: 16px;
  padding: 8px 12px;
}
```

Đoạn CSS này đặt kích thước chữ và khoảng đệm cho các phần tử `button`.

## Dễ nhầm với gì?

CSS không phải JavaScript. CSS tập trung vào cách hiển thị; JavaScript thường dùng để xử lý logic và tương tác động.
