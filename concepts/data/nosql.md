# NoSQL là gì?

NoSQL là tên gọi rộng cho các database không lấy mô hình relational table + SQL làm mô hình duy nhất hoặc trung tâm.

Nhóm này có nhiều kiểu khác nhau như document database, key-value store, wide-column store hoặc graph database.

## Ví dụ

MongoDB lưu document dạng gần JSON. Redis thường được dùng theo mô hình key-value. Hai hệ thống đều thường được xếp vào NoSQL nhưng cách lưu và truy vấn rất khác nhau.

## Dễ nhầm với gì?

NoSQL không có nghĩa “không dùng SQL trong mọi trường hợp”, và cũng không mặc định nhanh hơn relational database. Lựa chọn phụ thuộc loại dữ liệu và workload.
