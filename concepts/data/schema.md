# Schema là gì?

Schema là cấu trúc mô tả dữ liệu được tổ chức như thế nào trong một database.

Tùy hệ quản trị, schema có thể bao gồm table, column, kiểu dữ liệu, constraint và quan hệ giữa các phần dữ liệu.

## Ví dụ

Một database bán hàng có thể có table `customers`, `orders` và `products`. Schema mô tả các table đó có column nào và liên hệ với nhau ra sao.

## Dễ nhầm với gì?

Schema không phải dữ liệu thực tế. Schema mô tả cấu trúc; các row bên trong table mới là dữ liệu cụ thể.
