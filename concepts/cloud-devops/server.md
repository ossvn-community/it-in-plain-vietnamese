# Server là gì?

Server là máy tính hoặc chương trình cung cấp tài nguyên hay dịch vụ cho phía khác sử dụng qua một kết nối.

Một server có thể phục vụ website, API, file, database hoặc nhiều loại workload khác.

## Tại sao cần nó?

Trong Cloud & DevOps, server thường là nơi workload như website, API, database, CI runner hoặc application backend chạy.

Cloud có thể cung cấp server dưới nhiều hình thức khác nhau, nhưng concept server tồn tại độc lập với một cloud provider cụ thể.

Khái niệm client/server theo vai trò request/response được giải thích riêng ở [Client và Server](../web/client-server.md).

## Ví dụ

Một server có thể là máy vật lý, máy ảo hoặc một phần của hạ tầng lớn hơn tùy kiến trúc.
