# Serverless là gì?

Serverless là mô hình cloud trong đó developer tập trung vào code hoặc service, còn phần lớn việc cấp phát và vận hành server được platform quản lý.

“Serverless” không có nghĩa là không có server; server vẫn tồn tại nhưng người dùng không trực tiếp quản lý chúng như mô hình truyền thống.

## Ví dụ

Một function xử lý ảnh được gọi khi file mới được upload. Cloud provider có thể tự tạo môi trường chạy khi có request và scale xuống khi không dùng.

## Dễ nhầm với gì?

Serverless thường giảm công việc vận hành ban đầu nhưng có trade-off về vendor dependency, giới hạn runtime, cold start hoặc chi phí theo workload.
