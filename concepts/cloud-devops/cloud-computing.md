# Cloud Computing là gì?

Cloud Computing - điện toán đám mây - là cách sử dụng tài nguyên máy tính như server, storage hoặc database qua một nhà cung cấp và có thể cấp phát theo nhu cầu.

Thay vì luôn tự mua và vận hành phần cứng, bạn có thể thuê tài nguyên và thay đổi quy mô khi cần.

## Tại sao cần hiểu nó?

Cloud thay đổi cách team lấy và vận hành computing resources.

Thay vì luôn phải chuẩn bị hardware vật lý trước, nhiều resource có thể được provision qua software hoặc API.

## Một số đặc điểm nền tảng

NIST mô tả cloud computing với các đặc điểm như on-demand self-service, broad network access, resource pooling, rapid elasticity và measured service.

Không phải mọi hệ thống chạy trên server từ xa đều tự động đáp ứng đầy đủ định nghĩa cloud computing này.
