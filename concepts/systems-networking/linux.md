# Linux là gì?

Linux là kernel - phần lõi quản lý tài nguyên phần cứng và cung cấp nền tảng để hệ điều hành chạy chương trình.

Trong cách nói hàng ngày, “Linux” cũng thường được dùng để chỉ các hệ điều hành hoàn chỉnh xây quanh Linux kernel, như Ubuntu, Debian hoặc Fedora.

## Ví dụ

Một server Ubuntu dùng Linux kernel để quản lý process, memory, thiết bị và network. Ubuntu bổ sung nhiều công cụ, thư viện và phần mềm người dùng phía trên kernel.

## Dễ nhầm với gì?

Linux kernel không đồng nghĩa với một Linux distribution. Distribution là hệ điều hành hoàn chỉnh gồm kernel và nhiều thành phần khác.
