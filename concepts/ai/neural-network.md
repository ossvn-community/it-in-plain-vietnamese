# Neural Network là gì?

Neural Network - mạng nơ-ron - là một loại model Machine Learning gồm nhiều đơn vị tính toán kết nối thành các layer.

Trong quá trình training, các tham số của network được điều chỉnh để model dần tạo ra output phù hợp hơn với dữ liệu và mục tiêu học.

## Nó hoạt động thế nào?

Ở mức beginner, có thể hình dung dữ liệu đi qua nhiều lớp:

```text
Input
  ↓
Layer
  ↓
Layer
  ↓
Output
```

Mỗi lớp biến đổi dữ liệu dựa trên các parameter của model.

## Ví dụ

Neural network có thể được dùng trong nhận diện ảnh, xử lý âm thanh hoặc language model.

Deep Learning thường nói tới neural network có nhiều lớp xử lý.
