# Model là gì?

Model trong Machine Learning là phần đã học được pattern từ dữ liệu và có thể nhận input để tạo ra output như dự đoán, phân loại hoặc nội dung.

Có thể hình dung model là kết quả được tạo ra sau quá trình training và được dùng khi inference.

## Tại sao cần nó?

Các từ như training, inference, parameter, LLM hoặc neural network đều thường nói về model.

Hiểu model trước giúp các khái niệm đó dễ nối với nhau hơn.

## Ví dụ

Một model phân loại ảnh có thể nhận một ảnh làm input và trả về xác suất ảnh thuộc các nhóm như `cat`, `dog` hoặc `other`.

Application có thể dùng output đó để hiển thị kết quả cho người dùng.
