# Large Language Model là gì?

Large Language Model - mô hình ngôn ngữ lớn, thường viết tắt là **LLM** - là một loại Machine Learning model được huấn luyện trên lượng lớn dữ liệu ngôn ngữ để xử lý và tạo text.

LLM có thể được dùng cho chat, tóm tắt, dịch, viết code và nhiều tác vụ liên quan tới ngôn ngữ.

## LLM nằm ở đâu trong AI?

Một cách nhìn đơn giản:

```text
Artificial Intelligence
  └─ Machine Learning
      └─ nhiều loại model
          └─ Large Language Model
```

LLM tập trung vào language. Generative AI rộng hơn và còn có thể gồm model tạo image, audio, video hoặc các dạng dữ liệu khác.

## Ví dụ

Một chatbot có thể gửi prompt của người dùng tới LLM và nhận text response qua inference.

Nhưng hệ thống AI nhận diện vật thể trong camera không nhất thiết là LLM.

## Dễ nhầm với gì?

- **LLM** là một loại model.
- **Chatbot** là application có thể dùng LLM.
- **Generative AI** là nhóm AI rộng hơn, không chỉ text.
