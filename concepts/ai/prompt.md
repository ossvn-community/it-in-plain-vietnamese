# Prompt là gì?

Prompt là input hoặc tập chỉ dẫn được đưa vào model để yêu cầu model thực hiện một nhiệm vụ.

Với model ngôn ngữ, prompt có thể gồm câu hỏi, context, ví dụ, yêu cầu về format và các ràng buộc cần tuân theo.

## Ví dụ

Thay vì chỉ viết “Tóm tắt”, bạn có thể đưa tài liệu và yêu cầu: “Tóm tắt thành 5 ý, mỗi ý tối đa một câu, giữ nguyên các con số quan trọng.” Prompt rõ hơn giúp model hiểu nhiệm vụ và output mong muốn.

## Dễ nhầm với gì?

Prompt không phải code bảo đảm hành vi tuyệt đối. Output vẫn phụ thuộc model, context và cách hệ thống được cấu hình.
