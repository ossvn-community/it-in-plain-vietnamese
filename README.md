# IT in Plain Vietnamese

IT in Plain Vietnamese giải thích các khái niệm IT bằng tiếng Việt rõ ràng, dễ hiểu và chính xác cho người mới bắt đầu.

Nguyên tắc chính:

- Ưu tiên cách giải thích dễ hiểu.
- Giữ các thuật ngữ tiếng Anh cần thiết để người đọc có thể tra cứu.
- Nội dung kỹ thuật phải có nguồn đáng tin cậy để kiểm chứng.
